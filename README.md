# Tarea-3-SO-VPJC
Algoritmo de prioridades con ajuste dinámico

Para ejecutar el código deben hacer lo siguiente:

gcc simuladorPlanProcesos.c -o simuladorPlanProcesos.exe

.\simuladorPlanProcesos.exe ARCHIVO NUMERO

ARCHIVO va a ser un archivo txt donde se deberá de tener: El numero de procesos, llegada, ráfaga y prioridad. Y el NUMERO es el tiempo que debe esperar un proceso para que mejore su prioridad entre un rango de 3 a 10
